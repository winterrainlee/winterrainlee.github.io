이 블로그는 Astro로 빌드하고 GitHub Pages에 정적으로 배포합니다.

긴 글은 `src/content/articles`에 Markdown 또는 MDX로 작성하면 됩니다. 글을 추가한 뒤 `npm run build`를 실행하면 페이지와 RSS, 검색 인덱스가 함께 생성됩니다.

## 운영 메모

- 글은 Git으로 관리합니다.
- 검색은 Pagefind가 정적 인덱스를 만듭니다.
- 서버에는 별도 데이터베이스나 백엔드 프로세스가 필요하지 않습니다.
