블로그 내용은 서버에만 두기 때문에, 서버 기기를 쓰지 않고도 블로그를 편하게 발행할 수 있도록 플로우를 설계해 보았다. 

1. 기기 공용 옵시디언 보관함의 블로그 초안 폴더에 내가 글을 쓴다. 
2. 디스코드 에이전트에게 발행 준비 요청하면, **내용은 절대 손대지 않고** 파일 이름이나 태그 정도만 에이전트가 가다듬은 뒤 초안 글을 블로그용 옵시디언 보관함에 복사하고, 초안 플래그를 해제하고 커밋/푸시한 뒤 보고한다. 
3. 나는 블로그에 글이 올라오는지 확인하고 OK 사인을 준다. 
4. 에이전트가 초안 폴더에 있는 기발행 글을 삭제한다. 

한번에 되면 좋겠는데. 과연…!
