# 단어게임 어휘 데이터

## 목적

게임의 목표 어휘는 전술 기믹에 사용되는 단어와, 별도의 암기·복습 스테이지에서 익히는 단어를 분리하지 않고 하나의 전체 풀에서 관리한다.

현재 기준은 국립교육연구원(NAER)의 TBCL 三等七級詞語表 2025-04다.

- TBCL 4 / 4*: CEFR B1 목표 풀
- TBCL 5: CEFR B2 목표 풀
- 현재 추출 결과: B1 1,429개, B2 2,641개, 총 4,070개

## 분류 스키마

어휘를 왜 `공식 사용 상황 → 세부 주제 → 의미·학습·게임 기능`의 여러 층으로 관리하는지, 마을과 기믹을 왜 같은 분류로 고정하지 않는지에 대한 설계 설명은 [`VOCABULARY-SCHEMA.md`](./VOCABULARY-SCHEMA.md)에 정리한다.

핵심은 단어를 한 서랍에 넣는 것이 아니라, 전체 B1–B2 어휘를 보존하면서 세계·이야기·전술·일반 복습 스테이지에서 서로 다른 방식으로 다시 조합할 수 있게 하는 것이다.

## 파일

### `tbcl-b1-b2-master.csv`
사람이 검토하기 쉬운 전체 B1–B2 어휘표. 원자료 층이므로 게임 설계를 이유로 직접 수정하지 않는다.

### `tbcl-b1-b2-master.json`
웹앱 및 스테이지 생성 코드에서 읽기 위한 동일 데이터의 JSON 버전.

### `tbcl-b1-b2-source.json`
원자료 버전, 출처 URL, 생성 시각, 실제 추출 행 수를 기록한다.

### `word-game-overlay.json`
게임 편집층. 한국어 뜻, 세부 주제, 의미 태그, 암기 우선순위, 적합한 스테이지 방식, 마을 후보, 기믹 태그 등을 여기에 추가한다.

### `VOCABULARY-SCHEMA.md`
분류 스키마의 목적, 3층 구조, 필드 의미, 데이터 분리 원칙과 실제 활용 예시를 설명한다.

## 설계 원칙

1. 모든 B1–B2 단어는 master에 남긴다.
2. 전술 기믹으로 쓰기 어려운 단어도 삭제하지 않는다. 이 단어들은 일반 암기·판별·문맥 스테이지에서 사용할 수 있다.
3. `mechanic_eligible`은 단어의 학습 중요도가 아니라 '판 위에서 직접 행동으로 표현하기 좋은가'만 나타낸다.
4. 공식 TBCL 분류와 프로젝트가 덧붙인 주제·의미·게임 태그를 구분한다.
5. 한 단어에 여러 주제·마을·의미 태그를 허용하고, `primary_village`는 콘텐츠 진행을 위한 대표 배치로만 사용한다.
6. 마을별 전술 스테이지는 overlay에서 후보를 뽑고, 일반 어휘 스테이지는 master 전체를 대상으로 난이도·빈도·학습 이력에 따라 뽑는다.
7. 원자료가 갱신되면 `Refresh word-game TBCL vocabulary` GitHub Actions 워크플로로 master를 다시 생성한다.
