# 튜토리얼 직후 월드 설계 v0.1

기준 어휘: [`CORE-VOCAB-v0.1.md`](./CORE-VOCAB-v0.1.md)

## 목표

튜토리얼 `出發`이 끝난 직후 플레이어에게 월드맵을 열어준다.

첫 월드는 150개의 B1–B2 핵심 목표어를 한꺼번에 가르치는 구간이 아니다. 플레이어가 어디로 갈지 선택하면서 **같은 핵심어를 서로 다른 맥락에서 반복해서 만나기 시작하는 구간**이다.

구조는 다음과 같이 잡는다.

```text
                         邊境村
                      (권장: 關口鎮)
                         ↑
                         │
                關口鎮   │
                  ↖      │
                    出發 ───── 工坊村 ───→ 研究城
                  ↙        \                (후속 잠금)
              市集鎮        ↘
                            議會鎮
                       (권장: 市集鎮)
```

튜토리얼 직후에는 `關口鎮 / 工坊村 / 市集鎮` 세 곳이 자유롭게 열린다.

`邊境村 / 議會鎮`은 들어갈 수 있지만 선행 마을을 권장한다. 잠금은 하지 않는다.

`研究城`은 상태 변화와 조건 판정을 실제로 사용하므로 `工坊村`의 핵심 스테이지를 끝낸 뒤 열린다.

---

## 1. 關口鎮 — 길을 읽는 마을

### 역할

튜토리얼에서 배운 `接近 / 通過 / 到達`을 가장 자연스럽게 확장하는 첫 지역이다.

새 시스템을 많이 추가하지 않고 **경로·범위·순서·위치**의 차이를 세밀하게 만든다.

### 우선 목표어

`進入 / 通過 / 接近 / 到達 / 繼續 / 超過 / 退出 / 返回 / 遇到 / 距離 / 位置 / 範圍 / 停止 / 障礙 / 移動 / 前進 / 路線 / 周圍 / 帶領 / 追 / 經由 / 跟隨 / 目的地 / 後退`

### 스테이지 축

1. `進入 ↔ 退出` — 영역 안과 밖을 직접 오간다.
2. `前進 ↔ 後退` — 목표 방향과 실제 이동 방향이 다를 수 있다.
3. `距離 / 範圍 / 周圍` — 한 칸짜리 위험 범위에서 여러 칸짜리 영향권으로 확장한다.
4. `經由 / 路線 / 目的地` — 같은 목적지에 서로 다른 경로를 만든다.
5. `跟隨 / 帶領` — 다음 챕터의 NPC 조작을 예고한다.

### 일반 어휘 스테이지

모든 단어가 독립 기믹이 될 필요는 없다. `路線 / 周圍 / 目的地 / 障礙`처럼 명사성이 강한 말은 지도 읽기, 문맥 선택, 지시문 조합 스테이지에서 반복한다.

---

## 2. 工坊村 — 상태를 바꾸는 마을

### 역할

플레이어가 처음으로 **위치가 아니라 판의 상태를 조작**하기 시작한다.

스위치, 수문, 상자, 동력 장치처럼 결과가 눈에 보이는 오브젝트를 사용한다.

### 우선 목표어

`改變 / 增加 / 減少 / 控制 / 保持 / 避免 / 條件 / 調整 / 集中 / 發展 / 出現 / 分配 / 解決 / 處理 / 完成 / 改善 / 建立 / 維持 / 破壞 / 消失 / 恢復 / 限制 / 失敗 / 加強 / 取代 / 禁止 / 防止 / 允許 / 改進 / 代替`

### 첫 스테이지에서 우선할 소집단

`改變 / 保持`

`增加 / 減少`

`集中 / 分配`

`允許 / 禁止`

`出現 / 消失 / 恢復`

### 스테이지 축

1. 수치를 올리고 내린다 — `增加 / 減少`.
2. 상태를 바꾸거나 유지한다 — `改變 / 保持 / 維持`.
3. 자원을 여러 장치에 나눈다 — `分配 / 集中`.
4. 특정 조건일 때만 통과시킨다 — `條件 / 允許 / 禁止`.
5. 망가진 장치를 고친다 — `破壞 / 恢復 / 改善`.

이 마을의 마지막 시험을 통과하면 `研究城`이 열린다.

---

## 3. 市集鎮 — 자원을 고르는 마을

### 역할

전투가 아닌 **교환·선택·부족·가치 판단**으로 전략성을 만든다.

첫 월드에서 자원 개념을 가볍게 도입하는 지역이다. 숫자를 많이 계산하게 만들기보다 “무엇을 남기고 무엇을 쓸 것인가”가 중심이다.

### 우선 목표어

`提供 / 資源 / 生產 / 價值 / 效果 / 獲得 / 擁有 / 付出 / 價格 / 收入 / 競爭 / 剩下 / 需求 / 數量 / 負擔 / 缺少 / 取得 / 比例 / 足夠 / 費用 / 效率 / 交換 / 銷售 / 購買 / 供應`

### 관계 어휘 재등장

`接受 / 拒絕 / 支持 / 反對 / 公平`

이 단어들은 시장 마을 전용이 아니다. 거래와 선택 상황에서 먼저 자연스럽게 경험하게 한 뒤 다른 마을에서 다시 쓴다.

### 스테이지 축

1. 필요한 만큼만 확보한다 — `需求 / 足夠 / 缺少 / 剩下`.
2. 제한된 자원을 바꾼다 — `交換 / 取得 / 獲得`.
3. 효과가 다른 물건을 고른다 — `效果 / 價值 / 費用`.
4. 여러 NPC의 요구를 모두 만족시킬 수 없는 판을 만든다 — `負擔 / 分配 / 公平`.
5. 정답 하나가 아니라 서로 다른 거래 전략을 허용한다.

---

## 4. 邊境村 — 위험과 손실을 다루는 마을

### 접근

튜토리얼 직후에도 입장할 수 있다. 다만 월드맵에서 `關口鎮을 먼저 여행하면 길을 읽기 쉽다`고 권장한다.

강제 선행은 아니다.

### 우선 목표어

`挑戰 / 傷害 / 衝突 / 危機 / 救 / 意外 / 失去 / 威脅 / 穩定 / 受傷 / 風險 / 對抗 / 損失 / 緊急 / 突破 / 警告`

`戰爭 / 死亡 / 攻擊 / 犯罪`은 핵심 풀에는 남기되 첫 방문에서 적극적으로 가르치지 않고 후반 스토리·일반 어휘 스테이지용으로 둔다.

### 이유

빈도는 높지만 튜토리얼 직후 세계를 지나치게 전투·재난 중심으로 만들 필요는 없다. 초반에는 `위험을 예측하고 손실을 줄인다`는 전략 경험을 먼저 만든다.

---

## 5. 議會鎮 — 의견과 관계를 조정하는 마을

### 접근

튜토리얼 직후에도 갈 수 있다. `市集鎮`을 먼저 하면 선택과 자원 배분을 경험했기 때문에 권장 경로로 표시한다.

### 우선 목표어

`接受 / 支持 / 解釋 / 說明 / 表達 / 反對 / 責任 / 拒絕 / 懷疑 / 信任 / 公平 / 確定 / 負責 / 強調 / 互動 / 配合 / 尊重 / 規定 / 判斷 / 回應 / 確認 / 說服 / 權利 / 維護 / 聯絡 / 規則 / 原諒 / 投票 / 通知 / 誤會`

### 스테이지 축

이 지역부터 사람 사이 관계를 판 상태로 취급한다.

- 누구의 제안을 `接受 / 拒絕`할지 선택한다.
- 두 집단의 `支持 / 反對` 상태를 바꾼다.
- 정보를 `說明 / 解釋 / 確認`해서 오해를 푼다.
- `公平 / 責任 / 權利`처럼 격자로 직접 표현하기 어려운 말은 대화 선택과 결과 비교를 함께 사용한다.

여기서는 전술판과 일반 어휘 스테이지의 혼합 비율을 높인다.

---

## 6. 研究城 — 생각을 조합하는 첫 잠금 지역

### 해금

`工坊村`의 상태 조작 핵심 시험을 완료한다.

이 잠금은 단어 난이도를 이유로 하지 않는다. 이 지역의 퍼즐이 `상태를 바꾸고 → 결과를 비교하고 → 조건을 판단하는` 게임 문법을 전제로 하기 때문이다.

### 우선 목표어

`方式 / 主要 / 情況 / 過程 / 思考 / 分析 / 技術 / 資訊 / 證明 / 正確 / 內容 / 理解 / 真實 / 關鍵 / 錯誤 / 符合 / 對象 / 證實 / 整體 / 間接 / 區別`

### 역할

이 지역은 일반 어휘 문제를 전술 퍼즐 안에 적극적으로 넣기 시작하는 전환점이다.

예를 들어 두 장치의 결과를 비교한 뒤 `符合條件`인 쪽을 선택하거나, 여러 단서 중 `關鍵資訊`을 찾아야 다음 행동을 결정할 수 있다.

# 첫 월드의 실제 학습량

150개를 모두 첫 방문에 노출하지 않는다.

권장치는 다음과 같다.

- 한 마을 첫 방문: 새 목표어 약 12~18개
- 마을 전체 1차 진행: 약 20~30개
- 이미 다른 곳에서 본 단어 재등장: 전체 노출의 25~40%
- 한 스테이지의 새 목표어: 보통 1~3개
- 일반 어휘 스테이지: 기믹이 어려운 단어를 5~8개 단위로 묶음

따라서 플레이어가 첫 세 자유 마을을 조금씩 돌아다니면 40~60개 정도를 접하고, 이후 권장 지역까지 진행하면서 100개 안팎으로 자연스럽게 확장되는 흐름을 목표로 한다.

---

# B1–B2 목표어와 발판어를 구분한다

초반 게임에서 자주 필요한 말이 모두 B1–B2인 것은 아니다.

예를 들어 핵심 후보를 만들 때 `選擇`처럼 현재 B1–B2 master에 없는 단어도 여러 개 나왔다. 이런 말은 게임 문장과 안내에서 적극적으로 사용할 수 있지만 **B1–B2 신규 학습 목표 개수에는 세지 않는다.**

따라서 이후 데이터에는 다음 두 층을 구분한다.

- `target_core`: 이번 게임이 B1–B2 목표어로 집중 학습할 핵심 풀
- `scaffold`: 이미 더 낮은 단계에서 배웠거나 별도 확인이 필요한, 게임 진행을 위한 발판어

발판어는 오히려 새 B1–B2 단어를 이해시키는 문장을 단순하게 유지하는 데 필요하다.

---

# 다음 설계 단위

이제 전체 4,070개 분류보다 다음 순서가 우선이다.

1. 150개 핵심 풀을 사람이 한 번 빠르게 검토한다.
2. `關口鎮 / 工坊村 / 市集鎮`의 첫 5~6개 스테이지를 만든다.
3. 플레이하면서 어떤 단어를 실제로 자주 확인하는지 기록한다.
4. 그 기록으로 핵심 풀 v0.2를 수정한다.
5. 이후 필요한 순간에만 4,070개 전체 풀에서 새 단어를 끌어온다.
