# 튜토리얼 이후 초기 단계 기획서 v0.1

기준 문서:

- [`CORE-VOCAB-v0.1.md`](./CORE-VOCAB-v0.1.md) — 튜토리얼 직후 우선 사용할 B1–B2 핵심 목표어 150개
- [`POST-TUTORIAL-WORLD-v0.1.md`](./POST-TUTORIAL-WORLD-v0.1.md) — 첫 월드의 마을 구조와 역할
- [`VOCABULARY-SCHEMA.md`](./VOCABULARY-SCHEMA.md) — 전체 어휘와 게임용 분류를 함께 관리하는 이유와 구조
- 튜토리얼 「出發」 — `接近 / 遠離 / 通過 / 到達 / 避開`을 공간 행동으로 경험하고, 마지막에 멀리서 「救命！」이 들리는 지점까지

---

# 1. 이 문서의 목적

이 문서는 튜토리얼이 끝난 직후부터 첫 월드의 핵심 게임 문법이 자리를 잡을 때까지를 실제 플레이 흐름으로 정의한다.

초기 단계에서 확인하려는 것은 세 가지다.

1. 튜토리얼에서 익힌 **“단어의 의미를 이용해 판을 푼다”**는 경험이 여러 스테이지에도 이어지는가.
2. 월드맵에서 여러 마을 중 하나를 직접 선택하는 것이 **학습 순서의 자율성**으로 느껴지는가.
3. 전술 기믹 스테이지와 일반 어휘 스테이지를 섞었을 때, B1–B2 단어가 억지 문제풀이가 아니라 **모험 중 반복해서 만나는 언어**로 남는가.

이 구간은 150개의 핵심 목표어를 전부 가르치는 챕터가 아니다.

핵심 목표어를 먼저 작은 묶음으로 경험하고, 이미 본 단어를 다른 마을에서 다시 만나며, 이후 콘텐츠를 설계하기 위한 실제 플레이 로그를 얻는 구간이다.

---

# 2. 초기 단계의 한 줄 구조

> **出發 완료 → 월드맵 개방 → 세 자유 마을 중 선택 → 마을별 기믹·일반 어휘 스테이지 → 권장 지역 확장 → 工坊村 핵심 시험 후 研究城 개방**

월드 구조:

```text
                         邊境村
                      (권장: 關口鎮)
                         ↑
                         │
                關口鎮   │
                  ↖      │
                    出發 ───── 工坊村 ───→ 研究城
                  ↙        \                (후속 잠금)
              市集鎮        ↘
                            議會鎮
                       (권장: 市集鎮)
```

튜토리얼 직후 자유 입장:

- `關口鎮`
- `工坊村`
- `市集鎮`

초기부터 입장 가능하지만 권장 경로가 있는 지역:

- `邊境村` — `關口鎮` 선행 권장
- `議會鎮` — `市集鎮` 선행 권장

실제 잠금 지역:

- `研究城` — `工坊村`의 상태 조작 핵심 시험 완료 후 개방

잠금은 단어 난이도 때문에 사용하지 않는다.

**뒤 스테이지가 앞의 게임 문법을 실제로 전제로 할 때만 잠근다.**

---

# 3. 튜토리얼 종료와 월드맵 연결

튜토리얼 마지막에는 숲을 빠져나온 용사가 멀리서 다음 목소리를 듣는다.

> 「救命！」

이 목소리는 강제 퀘스트의 시작이 아니라 **첫 번째 소프트 가이드**로 사용한다.

월드맵이 열리면 `關口鎮` 방향의 길에 작은 긴급 표식이 나타난다.

예:

> 關口鎮 쪽에서 누군가의 목소리가 들린 것 같다.

그러나 플레이어는 `工坊村`이나 `市集鎮`을 먼저 선택할 수 있다.

이렇게 하면 이야기에는 자연스러운 추천 방향이 생기지만, 튜토리얼 직후부터 “내가 어디부터 갈지 정한다”는 월드 구조는 유지된다.

---

# 4. 어휘 운영 원칙

## 4.1 목표어와 발판어를 구분한다

초기 게임의 언어는 두 층으로 나눈다.

### `target_core`

이번 게임에서 집중적으로 익힐 B1–B2 목표어.

현재 v0.1 우선 풀은 150개다.

### `scaffold`

이미 더 낮은 급수에서 배웠거나, 목표어를 이해하고 게임을 진행하는 데 필요한 쉬운 말.

예:

- 選擇
- 決定
- 危險
- 安全
- 原因
- 結果
- 問題
- 幫助

이런 단어는 목표어 숫자에는 세지 않지만, 목표 문장·NPC 대화·도움말에서 자유롭게 사용할 수 있다.

게임이 B1–B2를 목표로 한다는 이유로 모든 문장을 B1–B2 신규 어휘만으로 구성하지 않는다.

---

## 4.2 첫 노출량

권장 범위:

- 한 스테이지의 새 목표어: **1~3개**
- 한 마을 첫 방문에서 새로 만나는 목표어: **12~18개**
- 한 마을의 1차 진행 전체: **20~30개**
- 이미 다른 곳에서 본 단어 재등장: 전체 노출의 **25~40%**

새 단어를 많이 보여주는 것보다, 같은 단어가 다른 상황에서 다시 의미를 가지는 것을 우선한다.

---

## 4.3 단어 확인은 항상 무료다

튜토리얼의 원칙을 그대로 유지한다.

단어 카드에서는 다음을 확인할 수 있다.

- 번체자
- 주음부호
- 한국어 핵심 뜻
- 짧은 예문
- 현재 게임에서 필요한 경우 기믹상 의미

단어를 확인해도 점수·보상·평가가 감소하지 않는다.

---

# 5. 한 마을의 기본 스테이지 묶음

초기 세 자유 마을은 공통적으로 **6~8개 정도의 1차 스테이지 묶음**을 가진다.

정확한 수는 플레이테스트에 따라 조정하지만 역할은 다음과 같이 나눈다.

## A. 도착 스테이지

- 마을의 문제와 분위기를 보여준다.
- 새 기믹을 많이 넣지 않는다.
- 튜토리얼에서 이미 본 단어 1개 + 새 단어 1개 정도가 좋다.

## B. 단일 개념 스테이지 2~3개

- 한 번에 의미 차이 하나를 경험한다.
- 예: `進入 ↔ 退出`, `增加 ↔ 減少`, `足夠 ↔ 缺少`.

## C. 일반 어휘 스테이지 1~2개

격자 기믹으로 직접 표현하기 어려운 단어를 다룬다.

가능한 방식:

- 문맥에 맞는 단어 선택
- 두 단어의 의미 차이 구별
- 지도·표·간단한 장면과 단어 연결
- 주음부호와 단어 연결
- 같은 의미군 안에서 적절한 단어 찾기

이 스테이지도 별도 시험 화면처럼 분리하지 않고 마을의 사건이나 의뢰 안에 넣는다.

## D. 혼합 전술 스테이지 1~2개

이미 본 단어를 동시에 사용한다.

정답 경로 하나만 요구하지 않고 여러 해결법을 허용한다.

## E. 마을 핵심 시험

해당 마을에서 배운 게임 문법을 스스로 조합한다.

- 단계별 공략 없음
- 단어 뜻 확인 가능
- 시간 제한 없음
- 여러 해법 허용

마을 핵심 시험 완료는 “이 단어들을 암기했다”는 판정이 아니라 **다음 게임 문법을 열어도 되는가**를 판단하는 진행 조건이다.

# 6. 關口鎮 — 첫 자유 지역 A

## 역할

튜토리얼과 가장 가까운 확장 지역.

새로운 시스템을 많이 추가하기보다 `接近 / 通過 / 到達`에서 시작해 **위치·경로·범위·순서**를 정교하게 만든다.

`救命！`의 첫 이야기 표식도 이 방향에 둔다.

## 첫 방문 목표어 후보

우선 14개 정도:

`進入 / 退出 / 距離 / 位置 / 範圍 / 移動 / 前進 / 後退 / 路線 / 周圍 / 經由 / 跟隨 / 帶領 / 障礙`

재등장:

`接近 / 通過 / 到達`

## 1차 스테이지 흐름 예시

### 關口-1 — 문 안으로

핵심:

`進入 / 退出`

작은 검문소 영역에 들어갔다가 다른 조건 때문에 다시 나와야 하는 판.

`進入`과 `到達`을 같은 것으로 착각하지 않게 한다.

### 關口-2 — 어느 정도 떨어져야 할까

핵심:

`距離 / 範圍`

튜토리얼의 늑대 위험 한 칸을 여러 칸짜리 영향 범위로 확장한다.

### 關口-3 — 길은 하나가 아니다

핵심:

`路線 / 經由`

같은 목적지로 가는 서로 다른 길을 보여준다.

짧은 길, 안전한 길, 특정 지점을 지나는 길이 모두 가능하게 만든다.

### 關口-4 — 지도 읽기

일반 어휘형.

`位置 / 周圍 / 障礙 / 路線`을 지도와 짧은 지시문에 연결한다.

### 關口-5 — 따라가거나 이끌거나

핵심:

`跟隨 / 帶領`

NPC 한 명을 처음으로 판에 넣는다.

아직 복잡한 동료 전투는 도입하지 않는다.

### 關口-6 — 관문 시험

`進入 / 退出 / 距離 / 經由 / 跟隨` 등을 조합한다.

여러 경로를 허용한다.

## 플레이 결과

關口鎮을 먼저 완료하면 `邊境村`의 위험·범위 퍼즐이 더 쉽게 느껴진다.

그러나 邊境村 입장을 막지는 않는다.

---

# 7. 工坊村 — 첫 자유 지역 B

## 역할

**위치 조작 → 상태 조작**으로 게임 문법을 넓히는 지역.

스위치, 수문, 동력 장치, 상자, 빛나는 결정 같은 오브젝트를 사용한다.

## 첫 방문 목표어 후보

우선 15개 정도:

`改變 / 保持 / 維持 / 增加 / 減少 / 調整 / 集中 / 分配 / 條件 / 允許 / 禁止 / 出現 / 消失 / 破壞 / 恢復`

재사용 후보:

`控制 / 改善 / 解決 / 完成`

## 1차 스테이지 흐름 예시

### 工坊-1 — 그대로 둘 것, 바꿀 것

`改變 / 保持`

두 장치 중 하나는 상태를 바꾸고 다른 하나는 그대로 유지해야 한다.

### 工坊-2 — 너무 많지도 적지도 않게

`增加 / 減少 / 調整`

숫자는 작게 유지한다.

계산 문제보다 “상태를 원하는 범위로 맞춘다”는 경험이 중심이다.

### 工坊-3 — 한곳에 모을까 나눌까

`集中 / 分配`

제한된 동력을 여러 장치에 배분한다.

### 工坊-4 — 열리는 조건

`條件 / 允許 / 禁止`

조건에 따라 통과 가능한 문이 달라진다.

### 工坊-5 — 고장과 복구

`破壞 / 消失 / 恢復`

한 장치를 고치기 위해 다른 상태를 포기할 수도 있게 만든다.

### 工坊-6 — 공방 시험

여러 상태를 조합해 최종 장치를 작동시킨다.

이 스테이지 완료 시 `研究城`이 열린다.

## 잠금의 의미

`研究城` 해금은 보상용 레벨 제한이 아니다.

연구도시 퍼즐이 “상태를 바꾼 뒤 결과를 비교하고 조건을 판단하는 것”을 전제로 하므로, 공방의 핵심 게임 문법이 먼저 필요하기 때문이다.

# 8. 市集鎮 — 첫 자유 지역 C

## 역할

전투 대신 **부족·가치·교환·선택**을 전략으로 만드는 지역.

초기에는 복잡한 경제 시뮬레이션을 만들지 않는다.

무엇을 남기고 무엇을 쓸지를 선택하는 작은 자원 퍼즐이 중심이다.

## 첫 방문 목표어 후보

우선 15개 정도:

`資源 / 提供 / 價值 / 效果 / 獲得 / 擁有 / 付出 / 剩下 / 需求 / 數量 / 缺少 / 足夠 / 費用 / 交換 / 取得`

관계어 재등장:

`接受 / 拒絕 / 公平 / 支持 / 反對`

## 1차 스테이지 흐름 예시

### 市集-1 — 필요한 만큼

`需求 / 足夠 / 缺少 / 剩下`

여러 물건 중 NPC에게 필요한 만큼만 전달한다.

### 市集-2 — 무엇을 바꿀까

`交換 / 取得 / 獲得`

한 자원으로 다른 자원을 얻는다.

### 市集-3 — 싸다고 항상 좋은 건 아니다

`價值 / 效果 / 費用`

가격만 비교하지 않고 용도까지 고려해야 한다.

### 市集-4 — 단어 의뢰

일반 어휘형.

짧은 상점 설명과 `價格 / 數量 / 費用 / 效果`를 연결한다.

### 市集-5 — 모두 만족시킬 수 없다

`付出 / 負擔 / 分配 / 公平`

모든 NPC 요구를 동시에 만족할 수 없는 판.

하나의 윤리적 정답을 강요하지 않고 조건상 가능한 여러 해를 허용한다.

### 市集-6 — 시장 시험

여러 거래 경로 중 자신이 원하는 방식으로 목표를 달성한다.

## 플레이 결과

市集鎮의 선택·배분 경험은 `議會鎮`의 사람 사이 의견 조정으로 자연스럽게 이어진다.

---

# 9. 권장 지역의 처리

## 邊境村

입장 자체는 처음부터 가능하다.

월드맵에는 다음 정도의 정보만 표시한다.

> 이 지역에는 위험 범위와 복잡한 길이 많다. 關口鎮을 먼저 둘러보면 도움이 될 수 있다.

플레이어가 그대로 들어가면 막지 않는다.

처음에는 `危機 / 風險 / 威脅 / 損失 / 緊急 / 救 / 受傷 / 突破` 같은 말부터 사용한다.

`戰爭 / 死亡 / 犯罪`처럼 세계 분위기를 크게 바꾸는 단어는 첫 방문 핵심으로 밀지 않는다.

## 議會鎮

입장 자체는 처음부터 가능하다.

추천 문구:

> 여러 사람의 요구를 조정해야 한다. 市集鎮에서 선택과 배분을 경험했다면 익숙할 수 있다.

`接受 / 拒絕 / 支持 / 反對 / 說明 / 解釋 / 確認 / 信任 / 懷疑 / 公平 / 說服` 등을 중심으로 한다.

전술 격자만으로 의미를 표현하기 어려운 단어가 많으므로 대화 선택·정보 확인·상태 변화와 일반 어휘 문제를 섞는다.

---

# 10. 研究城 — 초기 단계의 첫 도착점

`工坊村` 핵심 시험 완료 후 열린다.

이 지역에 도착하는 시점을 **초기 단계의 첫 번째 큰 이정표**로 본다.

## 역할

이전까지 배운 단어와 게임 문법을 “생각하는 도구”로 바꾼다.

우선 후보:

`方式 / 情況 / 過程 / 思考 / 分析 / 資訊 / 證明 / 正確 / 理解 / 真實 / 關鍵 / 錯誤 / 符合 / 區別`

예:

- 두 장치의 결과를 보고 `符合條件`인 것을 선택한다.
- 여러 정보 중 `關鍵資訊`을 찾는다.
- 서로 다른 `方式`의 결과를 비교한다.
- 틀린 가설과 `正確`한 가설을 판 위에서 검증한다.

이곳부터 일반 어휘 판별이 전술 퍼즐 안으로 더 깊게 들어간다.

# 11. 월드맵 UI 원칙

대상 기기: iPhone 13 mini Safari 세로 화면.

월드맵도 전술판처럼 한 화면에서 전체 관계를 읽을 수 있어야 한다.

초기 월드에서는 노드를 6개 정도만 보여준다.

노드 상태:

- **열림** — 바로 입장 가능
- **권장 표시** — 입장 가능하지만 선행 지역을 추천
- **잠김** — 게임 문법상 실제 선행 조건이 필요
- **완료/진행 중** — 진행 상태 표시

잠긴 지역도 숨기지 않는다.

플레이어가 “저곳은 나중에 갈 수 있다”는 목적지를 볼 수 있어야 한다.

월드맵에서 별점, 효율 점수, 최적 루트 평가는 표시하지 않는다.

# 12. 학습 상태 기록

초기 구현에서는 복잡한 숙련도 모델보다 실제 설계에 필요한 로그부터 저장한다.

단어별 최소 기록 후보:

- `seen_count` — 화면에서 의미 있게 노출된 횟수
- `lookup_count` — 단어 카드를 열어본 횟수
- `mechanic_success_count` — 해당 단어가 핵심인 기믹을 성공한 횟수
- `context_correct_count` — 일반 어휘 스테이지에서 맞춘 횟수
- `context_attempt_count`
- `last_seen_at`

이 기록은 플레이어에게 평가 점수로 보여주기 위한 것이 아니라, 다음 버전의 콘텐츠를 고르기 위한 자료다.

예:

- 자주 확인하지만 계속 틀리는 단어 → 재등장 빈도 증가
- 기믹에서는 이해했지만 문맥 문제에서 약한 단어 → 일반 어휘 스테이지로 재노출
- 여러 마을에서 안정적으로 처리한 단어 → 새 단어를 설명하는 발판으로 활용

- 시간 제한
- 에너지·목숨
- 일일 퀘스트
- 반복 파밍
- 단어 암기율 하나로 지역을 잠그는 구조
- 모든 마을을 일렬로 강제하는 챕터 진행

먼저 **월드 선택 + 단어 기반 전술 + 일반 어휘 복습**이라는 핵심 루프가 재미있는지 확인한다.

# 14. 초기 구현 우선순위

## Milestone 1 — 월드맵 전환

튜토리얼 완료 후 월드맵이 열린다.

- 3개 자유 마을
- 2개 권장 마을
- 1개 잠금 마을
- 현재 위치와 진행 상태

## Milestone 2 — 關口鎮 1차 묶음

튜토리얼과 가장 가까운 이동·공간 기믹을 구현한다.

먼저 5~6개 스테이지로 실제 재미를 검증한다.

## Milestone 3 — 工坊村 1차 묶음

상태 조작 문법을 구현한다.

`研究城` 해금 조건까지 연결한다.

## Milestone 4 — 市集鎮 1차 묶음

작은 자원 퍼즐과 일반 어휘 스테이지를 함께 구현한다.

## Milestone 5 — 실제 플레이 로그 기반 조정

첫 세 마을에서 수집한 로그를 바탕으로 150개 핵심 풀을 v0.2로 조정한다.

이 시점에 처음으로 다음을 판단한다.

- 너무 자주 등장하는 단어
- 거의 쓰이지 않는 단어
- 기믹으로는 좋지만 학습 효과가 약한 단어
- 일반 어휘 스테이지에서 반드시 필요한 단어
- 초반 풀에서 빼고 뒤로 미룰 단어
