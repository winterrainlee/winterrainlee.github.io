# 단어게임 어휘 분류 스키마

## 왜 이 스키마를 만드는가

이 프로젝트의 목표는 B1–B2 어휘를 단순한 단어장으로 외우게 하는 것이 아니라, 일부 단어는 전술 기믹을 통해 의미를 체험하고 나머지 단어도 별도의 암기·판별·문맥 스테이지에서 꾸준히 익히게 하는 것이다.

따라서 하나의 분류 기준만으로는 충분하지 않다.

TBCL의 `情境` 분류는 **그 단어를 어떤 생활·사회적 상황에서 만날 가능성이 높은가**를 알려준다. 이것은 월드맵의 지역과 마을을 설계하는 데 유용하다. 그러나 `控制`, `調整`, `比較`, `支持`처럼 여러 상황에서 쓰이는 B1–B2 단어의 의미 관계나 게임 동작까지 설명해주지는 않는다.

반대로 `이동`, `거리`, `변화`, `선택`, `협상` 같은 게임용 분류만 사용하면 스테이지 기믹은 만들기 쉽지만, 단어가 실제로 사용되는 사회적·생활적 맥락을 잃게 된다. 또한 기믹으로 표현하기 어려운 수많은 B1–B2 단어가 학습 풀에서 밀려날 위험이 있다.

그래서 이 프로젝트에서는 **출처의 분류와 게임의 분류를 겹쳐서 사용한다.**

핵심 목적은 다음 다섯 가지다.

1. **전체 B1–B2 어휘를 버리지 않는다.** 전술 기믹에 적합하지 않은 단어도 일반 학습 스테이지의 대상이다.
2. **마을과 세계는 실제 사용 맥락으로 묶는다.** 시장, 교통, 안전, 사회, 감정 같은 장소·상황이 어휘의 배경이 된다.
3. **스테이지는 의미 작용으로 묶는다.** 이동, 변화, 비교, 판단, 설득처럼 플레이어가 실제로 해야 하는 사고와 행동을 태그로 관리한다.
4. **같은 단어를 여러 방식으로 다시 만날 수 있게 한다.** 한 단어가 한 마을이나 한 기믹에 영구 고정되지 않는다.
5. **공식 자료와 게임의 해석을 섞지 않는다.** TBCL 원자료가 갱신되어도 게임용 분류를 별도로 유지하고 검토할 수 있다.

---

## 3층 분류 구조

### 1층 — 공식 원자료 / 사용 상황

출처: TBCL master.

대표 필드:

- `word`
- `tbcl_level`
- `cefr`
- `category` — TBCL `情境`
- `zhuyin`
- `pinyin`
- 구어·서면 빈도

이 층은 **원자료 층**이다. 게임 설계 때문에 값을 바꾸지 않는다.

질문으로 표현하면:

> 이 단어는 어느 수준이며, 어떤 상황에서 쓰이는가?

월드맵과 마을의 큰 주제는 주로 이 층을 참고한다.

---

### 2층 — 세부 주제

예:

- 교통 → 대중교통 / 개인 교통 / 여행 / 관광정보
- 사회 → 정치 / 경제 / 법률 / 국제
- 안전 → 범죄 / 충돌 / 경찰·소방
- 감정·태도 → 감정 / 태도 / 반응

`topic_tags`는 하나의 값으로 제한하지 않는다. 중고급 단어는 여러 상황에서 사용되기 때문이다.

이 층은 TBCL의 세부 상황 분류나 다른 교육용 분류체계를 참고해 만든다. **공식 자료에서 단어별 세부 주제가 직접 제공되지 않는 경우에는 프로젝트의 편집 분류임을 명확히 한다.**

질문으로 표현하면:

> 이 단어를 어떤 이야기와 생활 장면 속에서 다시 만날 수 있는가?

마을 안의 지구, NPC 역할, 일반 어휘 스테이지의 주제를 만드는 데 사용한다.

---

### 3층 — 의미·학습·게임 기능

이 층은 단어가 **무엇을 의미하고, 플레이어가 그것으로 무엇을 할 수 있는가**를 표현한다.

예시 의미 태그:

- 공간
- 이동
- 거리
- 방향
- 변화
- 증가·감소
- 유지
- 분배
- 비교
- 선택
- 원인·결과
- 판단
- 인지
- 감정
- 관계
- 협력
- 갈등
- 설득
- 규칙
- 위험

예시 기믹 태그:

- `move`
- `distance`
- `avoid`
- `state_change`
- `resource_allocation`
- `compare`
- `choose`
- `negotiate`
- `protect`
- `sequence`

질문으로 표현하면:

> 이 단어는 다른 단어와 어떤 의미 관계를 가지며, 어떤 학습 행동이나 게임 행동으로 표현할 수 있는가?

---

## 왜 마을과 기믹을 같은 분류로 만들지 않는가

마을은 **맥락**이고 기믹은 **의미 작용**이기 때문이다.

예를 들어 `比較`는 시장에서는 상품을 비교하는 데 쓰일 수 있고, 연구도시에서는 데이터를 비교하는 데 쓰일 수 있다. `控制`도 공방에서는 장치를 제어하고, 안전 지역에서는 위험을 통제하는 식으로 재사용할 수 있다.

따라서 `比較 = 시장 마을`처럼 고정하면 단어의 실제 활용 폭을 지나치게 좁히게 된다.

이 프로젝트에서는 마을을 단어의 집이 아니라 **그 단어를 다시 만날 수 있는 맥락 중 하나**로 본다.

---

## 일반 어휘 스테이지와의 관계

`mechanic_eligible = false`는 중요하지 않은 단어라는 뜻이 아니다.

오직

> 이 단어의 의미를 격자판 위의 행동이나 상태 변화로 직접 표현하기 쉬운가?

만 나타낸다.

기믹에 적합하지 않은 단어는 다음과 같은 일반 학습 스테이지에서 사용할 수 있다.

- 뜻 고르기
- 문맥에 맞는 단어 고르기
- 유의어·반의어 구별
- 여러 문장 중 자연스러운 쓰임 찾기
- 한자 구성이나 형태 비교
- 주음부호와 단어 연결
- 같은 주제의 단어 묶기
- 이미 배운 기믹 단어와 새 추상어 연결하기

따라서 전체 어휘 풀과 전술 기믹 풀은 경쟁 관계가 아니라 **같은 학습 시스템의 두 사용 방식**이다.

---

## overlay 필드

원자료 master에는 손대지 않고 `word-game-overlay.json`에 다음 정보를 붙인다.

| 필드 | 용도 |
|---|---|
| `korean_gloss` | 게임에서 보여줄 한국어 핵심 뜻 |
| `study_priority` | `core / normal / optional` |
| `topic_tags` | 세부 상황·주제. 복수 허용 |
| `semantic_tags` | 의미 관계 태그. 복수 허용 |
| `study_tags` | 형태·유의어·반의어 등 복습 태그 |
| `mechanic_eligible` | 전술 기믹 직접 표현 적합 여부 |
| `mechanic_tags` | 사용할 수 있는 전술 기믹 |
| `stage_modes` | 이 단어에 적합한 학습 스테이지 방식 |
| `primary_village` | 현재 대표적으로 배치한 마을. 없을 수 있음 |
| `village_tags` | 다시 등장할 수 있는 마을·지역. 복수 허용 |
| `related_words` | 함께 익히기 좋은 관련어 |
| `contrast_words` | 의미 차이를 비교하기 좋은 단어 |
| `classification_status` | `unreviewed / assisted / reviewed` |
| `notes` | 설계 메모 |

`primary_village`는 콘텐츠 진행을 위한 편의값일 뿐, 단어의 의미 범위를 제한하지 않는다.

## 데이터 분리 원칙

### Master

공식 출처에서 가져온 사실을 저장한다.

> 무엇이 원자료에 있었는가?

### Overlay

게임 제작자가 내린 해석과 설계 결정을 저장한다.

> 우리는 이 단어를 어떻게 가르치고 사용할 것인가?

두 층을 분리하면 TBCL 목록이 갱신되어도 게임 태그를 잃지 않고, 반대로 게임 분류가 바뀌어도 공식 등급과 발음 정보가 오염되지 않는다.

---

## 분류할 때 지킬 원칙

1. 한 단어에 여러 태그를 허용한다.
2. 분류는 정답을 하나 고르는 작업이 아니라 검색과 조합을 돕는 메타데이터 작업으로 본다.
3. `mechanic_eligible`과 학습 중요도를 혼동하지 않는다.
4. 자동 분류나 AI 보조 분류는 `assisted`로 표시하고 사람이 확인한 뒤 `reviewed`로 바꾼다.
5. 공식 분류와 프로젝트 편집 분류를 UI나 데이터에서 구별할 수 있게 한다.
6. 마을 때문에 단어의 의미를 억지로 좁히지 않는다.
7. 스테이지 설계가 발전하면 태그도 수정할 수 있다. 스키마는 학습 설계를 돕는 도구이지 고정된 사전 분류가 아니다.

---

## 이 스키마가 최종적으로 가능하게 하는 것

예를 들어 다음과 같은 질의를 할 수 있어야 한다.

- `安全` 상황에 속하면서 `위험/회피` 기믹에 적합한 B1 단어를 보여줘.
- 시장 마을에서 쓸 수 있는 B2 단어 중 `비교/선택` 태그가 붙은 것을 보여줘.
- 전술 기믹에는 쓰지 않았지만 이번 마을에서 아직 배우지 않은 핵심 단어 8개를 골라줘.
- `增加`와 대비해서 가르칠 단어를 찾아줘.
- 최근 틀린 `社會` 주제 단어만 모아 문맥 선택 스테이지를 만들어줘.
- 이미 다른 마을에서 배운 단어를 현재 이야기 맥락에 자연스럽게 재등장시켜줘.

즉 이 스키마의 목적은 **단어를 서랍에 넣는 것**이 아니라,

> 전체 B1–B2 어휘를 잃지 않으면서, 세계·이야기·전술·복습을 같은 데이터에서 자유롭게 조합할 수 있게 만드는 것

이다.
